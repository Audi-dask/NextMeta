## 一键安装

```bash
curl -fsSL https://raw.githubusercontent.com/Audi-dask/NextMeta/main/install.sh | bash
```

启动后访问 `http://localhost:8080`，默认管理员 `NextMeta / password123`（登录后请立即修改）。
