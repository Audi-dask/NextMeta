# 简介

NextMeta 是一款轻量级、简约风的数据库 SQL 审核平台，聚焦安全防护与性能优化，为团队提供统一的查询入口、工单审批和审计追踪能力。

## 核心能力

- **安全 SQL 查询工作台**：多数据源切换、SQL 语法高亮、结果导出、库表级容量统计
- **SQL 审计与规则引擎**：语法与风险检查，可配置阻断 / 警告级规则
- **工单流转与审批**：查询 / 变更 / 导出工单，Explain 预检与执行结果归档
- **团队与权限（RBAC + LDAP）**：基于组的数据源访问与审批权限管控
- **数据脱敏**：按数据源 / 库表 / 字段维度配置脱敏规则
